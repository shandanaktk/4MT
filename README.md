# 4MT Frontend

React landing page for 4MT, built with Vite + Tailwind CSS.

## Getting started

```bash
cd frontend
npm install
npm run dev
```

The dev server runs at [http://localhost:5173](http://localhost:5173).

## Project structure

- `frontend/src/components/Navbar.jsx` — fixed navigation bar
- `frontend/src/components/Hero.jsx` — hero section with `hero.jpg` background
- `frontend/public/hero.jpg` — hero background image
